This folder holds one rendered WAV per Ableton track.
How to bounce in Ableton Live:

1. Select your tracks in the Arrangement.
2. Ctrl/Cmd+Shift+R (Freeze+Flatten won't be needed) OR use File > Export Audio/Video.
3. Choose: Rendered Loop = off, Sample Rate 44100, Bit Depth 24.
4. Name each file by its role so auto-mix can detect it:
     Kick.wav  Sub.wav  Bass.wav  Snare.wav  HiHat.wav  Lead.wav  Pads.wav  Vocals.wav

Example expected files:
    renders\Kick.wav
    renders\Sub.wav
    renders\Bass.wav
    renders\Lead.wav
    renders\Pads.wav
    renders\HiHat.wav

Then ask: "сведи renders в стиле techno, покажи что менять"
