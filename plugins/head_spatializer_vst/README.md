# Head Spatializer 3D — Standalone VST3 & CLAP Audio Plugin

Профессиональный VST3/CLAP плагин для бинаурального 3D-позиционирования звука вокруг головы человека (от основания шеи и затылка до ушей и лица) на базе психоакустических задержек ITD, затенения черепом ILD и спектральной фильтрации затылка/шеи.

---

## 🎧 Параметры плагина
* **Head Trajectory (0.0 — 1.0):** траектория перемещения источника звука:
  - `0.0 – 0.2` = Шея (Neck Sub & Warmth)
  - `0.2 – 0.45` = Затылок (Occiput Behind)
  - `0.45 – 0.75` = Прямое ухо (Direct Ear)
  - `0.75 – 1.0` = Перед лицом (Front Soundstage)
* **Azimuth (-90° — +90°):** горизонтальный угол (влево / вправо).
* **Elevation (-45° — +45°):** вертикальный угол (вниз к шее / вверх к макушке).
* **Distance (0.3m — 3.0m):** акустическая дистанция до головы.
* **Mix (0% — 100%):** соотношение Dry/Wet.

---

## 🛠️ Как собрать VST3 плагин на Windows

Для сборки плагина требуется установленный Rust (`cargo`):

1. **Сборка плагина:**
   ```powershell
   cd "plugins\head_spatializer_vst"
   cargo build --release
   ```

2. **Установка в Ableton Live / DAW:**
   - Скопируйте скомпилированный `.vst3` / `.clap` файл в стандартную системную папку плагинов:
     `C:\Program Files\Common Files\VST3\`
   - Откройте Ableton Live $\to$ Preferences $\to$ Plug-Ins $\to$ **Rescan**.
   - Плагин появится в списке аудиоэффектов под именем **«Head Spatializer 3D»**.
